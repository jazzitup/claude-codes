# 논문 observable 설명 영상 (event display → 분포 → 논문 결과)

## 0. 무엇을 만드나
청중이 "이 그림의 x축 값 하나가 이벤트 하나에서 어떻게 나오는지"를 눈으로 보게 하는 30–70초 영상.
기본 줄거리는 5단계 (`vstyle.steps`로 왼쪽 위에 진행 표시):

| 단계 | 내용 | 예 (tt̄ cos φ) | 예 (OO/NeNe ε₂, 기존 영상) |
|---|---|---|---|
| 1 | 이벤트 하나의 event display가 vertex에서 자라남, 객체 라벨 | e⁺, μ⁻, b jet 2개, p_T^miss | 핵 두 개 충돌 |
| 2 | 재구성 + 분석 컷 | t, t̄ 짝짓기, m(tt̄)·β_z 컷 | participant, overlap |
| 3 | 그 이벤트에서 observable 계산 (기하) | tt̄ 정지계 → 각 top 정지계 → ℓ̂⁺·ℓ̂⁻ | 이심률 타원 |
| 4 | 이벤트가 쌓여 분포가 됨 (처음 ~10개는 하나씩, 그 뒤 지수적으로 가속) + 평균·추출 값 실시간 + 기준선 | ⟨cos φ⟩, D = −3⟨cos φ⟩, D = 0 / −1/3 / −1 | ε₂ 히스토그램 |
| 5 | 논문 실제 결과: 원본 그림 + 핵심 숫자 | Fig. 6, D = −0.480, 5.1σ | CMS v₂ 비율 |

## 1. 파일 위치 (사용자 규칙)
- 플러그인 `paper-plot-animator` (마켓플레이스 `claude-codes` = `~/claude-codes`, git 동기화). 라이브러리: `${CLAUDE_PLUGIN_ROOT}/lib/`
  (= `~/claude-codes/plugins/paper-plot-animator/lib/`). 영상 스크립트는 예제의 `_ppa_lib()`로 찾는다($PPA_LIB → git checkout → 플러그인 캐시).
  - `vstyle.py` — 기존 `movie/claude_tools/vstyle.py` 복사본 + 글꼴 fallback(Arial Unicode MS, DejaVu) + **`save()`가 서명을 자동으로 찍음**(중복 없음)
  - `kin.py` — 4-vector, boost, 정지계 변환, 2체 붕괴, 선형 분포 샘플링
  - `detector.py` — CMS형 횡단면 event display (`EventDisplay`: track/tower/jet/met, `prog`로 성장, `emph`로 강조)
  - `harness.py` — `main(frame, T_END, FPS)`: `OUTDIR [lo:hi] [--preview t,..] [--jobs N] [--encode OUT.mp4]`
  - `paperdata.py` — `fetch ARXIVID OUT`(arXiv 소스 + HEPData), `markers FIG.pdf`(벡터 PDF 데이터 점), `raster FIG.pdf OUT.png`
- 영상 스크립트: `~/Library/CloudStorage/Dropbox/My transparencies/movie/claude_tools/<주제>/<이름>_v1.py` (+ `assets/`)
- 완성 영상: `movie/videos/<발표 또는 주제>/` — **프레임 PNG는 Dropbox 밖(세션 스크래치패드)에서 렌더링**
- 기록: `movie/logs/<영상 이름> 작업 기록.md` 새로 만들고, `movie/README 이어서 작업하기.md`의 표에 줄 추가
- 예: `${CLAUDE_PLUGIN_ROOT}/examples/ttbar_cosphi_v1.py` (tt̄ cos φ, 62 s, 영상 `movie/videos/observables/ttbar_entanglement_cosphi_v1.mp4`) — 새 영상은 이걸 복사해 시작
- 고칠 땐 새 버전 번호로 복사(v2, v3…), 원본 영상·스크립트 덮어쓰지 않음

## 2. 절차
1. **논문 읽기**: `python lib/paperdata.py fetch <arXiv> <scratch>/paper` → `src/*.tex`에서
   - observable 정의 식(예: `\cosphi = \hatlp\cdot\hatlm`, 어느 정지계에서), 분포의 이론형(½(1 − D cos φ)),
   - money plot의 캡션·컷(345 < m(tt̄) < 400 GeV, β_z < 0.9), 최종 숫자(초록/결론), 저널 정보(Crossref로 확인)를 뽑는다.
   - 숫자는 **원문에서 그대로**. 지어내지 않는다.
2. **실제 데이터**: HEPData 표가 있으면 그것. 없으면 `paperdata.py markers Figure_00X.pdf` — 눈금 글자로 축을 맞추고 채워진 검은 마커 중심을 출력(범례 마커는 범위 밖 값으로 걸러냄). 원본 그림을 그대로 보여 줄 땐 `raster`로 4배 PNG.
3. **스토리보드**: 위 5단계 표를 그 논문에 맞게 채워 사용자에게 한 줄씩 보여 주고 바로 진행(질문은 정말 갈리는 것만).
4. **이벤트 만들기**: `kin.py`로 진짜 운동학을 가진 toy 이벤트를 만들고, 화면에 보이는 observable 값은 **그 이벤트에서 실제로 계산**한다. `good()` 같은 조건으로 시드를 훑어 화면에서 객체끼리 안 겹치는 이벤트를 고른다(Δφ > 0.75 등).
   - 검증: 스핀 상관 없는 toy에서 ⟨cos φ⟩ ≈ 0, m(ℓbν) = m_t, m(ℓν) = m_W 같은 sanity check를 반드시 돌린다.
5. **많은 이벤트**: 이론 분포에서 측정값으로 샘플링(`kin.sample_linear`)한 toy임을 화면에 명시("illustration: parton-level toy …"). 검출기 수준 그림(논문)과 parton 수준 toy를 섞어 말하지 않는다.
6. **미리보기**: `--preview 4,9,17,…` 로 장면마다 한 장 → 4장씩 붙인 contact sheet로 확인 → 겹침·깨진 글자 수정.
7. **본 렌더링**: `--jobs <코어수>` (30 fps 62 s = 1860 프레임) + `--encode`. 결과를 `movie/videos/…`로 복사하고 contact sheet로 최종 확인.
8. **기록**: 영상 기록 md + README 표 + 해당 세션 로그.

## 3. 스타일·함정 (실제로 겪은 것)
- **서명 "Generated by Yongsun"(Montserrat Bold Italic, 파랑 RGB 58,124,203, 오른쪽 아래)은 모든 프레임에 항상** (2026-11-08 사용자 지시). vstyle.save()가 보장. manim 등 다른 렌더러를 쓰면 직접 넣고 contact sheet에서 확인.
- 해상도 1440×1080, **기본 30 fps** (2026-11-08 사용자 지시: 모든 영상은 기본 30 fps; 60 fps는 요청할 때만. 예시 영상이 60 fps여도 따라가지 않는다).
- **mathtext 문자열(`$…$`가 하나라도 있는 문자열)은 글꼴 fallback이 안 된다** → 그 안의 →, ✓는 `$\rightarrow$`, `$\checkmark$`로. `$`가 없는 문자열은 vstyle의 fallback으로 →, ✓, t̄가 정상 출력.
- `t̄`, `b̄`는 mathtext `$t\bar{t}$` 쓰는 게 깔끔. `β_z`는 `$\beta_z$` (밑줄이 그대로 찍힘).
- ①②③ 같은 원문자는 Helvetica Neue에 없음 → "1." 식으로.
- 라벨은 객체 방향 반경 + 수직 오프셋(`obj_anchor`)으로 놓아 트랙·타워와 안 겹치게. 아래쪽 pill(y ≈ −4.3)과 뮤온 라벨 충돌 주의.
- 히스토그램 초반(이벤트 몇 개)은 이벤트 하나 = 고정 높이 토큰, N이 커지면 정규화 밀도로 자연스럽게 넘어가게: `scale = min(token, 1/(N·binwidth))`.
- threshold 근처 tt̄처럼 모체가 느리면 붕괴 산물이 사방으로 흩어짐 → t/t̄ 소속은 평균 방향 배지가 아니라 **각 객체 옆 배지+글로우**로 표시.
- `rm -f $VAR/*.png` 식 삭제는 안전 검사에 막힘 → 새 폴더에 렌더링하거나 `"${S:?}"/*.png`.
- ffmpeg: PATH에 없으면 imageio-ffmpeg 바이너리(`harness.ffmpeg_exe`가 자동 선택). Python은 `~/.venvs/research/bin/python`(numpy, matplotlib, pillow, imageio-ffmpeg, pymupdf).

## 3b. 멈춤(pause)과 음악
- 사용자가 "N초에서 M초 멈춰"라고 하면 **원래 타임라인 시각 기준** `HOLDS = [(N, M), …]`, `warp, extra = harness.make_warp(HOLDS)`,
  `T_END = 원래길이 + extra`, `frame(t_out)` 안에서 `t = warp(t_out)`. 화면만 멈추고 음악은 계속.
  "라벨 나오고 3초 쉬어"는 그 라벨이 다 나타난 시각(ramp 끝)에 hold.
- 음악: `harness.add_music(video, music)` → `<video>_music.mp4` (영상 길이로 자르고 1 s fade-in, 3 s fade-out, AAC 192k).
  사용자 본인이 만든 음악이면 저작권 확인 불필요(사용자 말). 예: `~/Library/CloudStorage/Dropbox/K 고분 헌터스/음악모음/`.
- 예: `examples/ttbar_cosphi_v2.py` (9·20 s에 5 s, 기준선마다 3 s, CMS 측정선 뒤 5 s; 62 → 86 s).

## 4. 다른 observable에 적용할 때
- 검출기가 ATLAS/ALICE면 `detector.LAYERS`/`COL`만 바꿔도 비슷한 느낌. 종단면(ρ-z) 뷰가 필요하면 `detector.py`에 함수 추가.
- 3D 벡터 그림은 예제의 `rotm/proj/sphere/arrow3/angle_arc` 함수를 그대로 가져다 쓴다(다음에 두 번째로 쓰게 되면 `lib/geom3d.py`로 옮길 것).
- 중이온(ε₂, v₂, 2입자 상관) 류는 `movie/claude_tools/oo_nene_v3.py`, `pair_corr_v5.py`가 더 가까운 원형.
