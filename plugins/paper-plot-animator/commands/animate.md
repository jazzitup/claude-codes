# /paper-plot-animator:animate

요청: $ARGUMENTS

1. 먼저 이 플러그인의 스킬 `paper-plot-animator`의 SKILL.md를 읽고 그 절차를 그대로 따른다
   (`${CLAUDE_PLUGIN_ROOT}/skills/paper-plot-animator/SKILL.md`).
2. 인자에서 논문(arXiv ID/URL/DOI)과 대상 플롯(그림 번호·observable 이름)을 뽑는다. 둘 중 하나가 빠졌으면 그것만 짧게 묻는다.
   플롯이 모호하면(그림에 패널이 여러 개 등) 논문을 읽은 뒤 "money plot은 Fig. N (왼쪽) — 이걸로 합니다"라고 알리고 진행한다.
3. 라이브러리: `${CLAUDE_PLUGIN_ROOT}/lib/` (vstyle, kin, detector, harness, paperdata). 예제: `${CLAUDE_PLUGIN_ROOT}/examples/ttbar_cosphi_v1.py`.
4. 반드시 지킬 것: **30 fps**(60은 사용자가 요청할 때만), **모든 프레임 오른쪽 아래 "Generated by Yongsun"**(vstyle.save가 자동으로 붙임 — vstyle을 안 쓰는 렌더러면 직접 넣는다), 숫자는 논문/HEPData 원문 그대로, toy 부분은 화면에 'illustration' 명시.
5. 끝나면 영상 경로, 길이, 장면별 요약, contact sheet 확인 결과를 보고한다.
