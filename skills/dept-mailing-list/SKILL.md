# 물리천문학과 교수 메일링 리스트

## 0. 절대 규칙
- 이 SKILL.md는 공개 GitHub repo(`jazzitup/claude-codes`)에 있다. **이메일 주소·이름 목록을 이 파일이나 repo 어디에도 적지 않는다.**
- 목록은 Dropbox 파일에만 있다 (Dropbox 동기화로 다른 컴퓨터에서도 보임):
  `~/Library/CloudStorage/Dropbox/01. 개인서류/contacts/물리천문학과_교수_메일링리스트.md`
- 메일은 사용자가 명시적으로 '보내'라고 하기 전에는 보내지 않는다. 초안(Gmail draft)까지만.

## 1. 사용법
1. 위 Dropbox 파일을 읽는다. 파일이 없으면 Dropbox 동기화 상태를 확인하라고 사용자에게 알린다(목록을 지어내지 않는다).
2. 요청에 맞게 돌려준다.
   - "리스트 알려줘" → '받는사람 칸에 바로 붙여넣는 형태' 줄을 그대로 보여준다.
   - Gmail 초안 작성 → `to`에 '주소만' 목록을 넣는다. 사용자 본인 주소(파일에 표시됨)는 보통 빼고, 필요하면 물어본다.
3. 목록이 바뀌었다고 하면(교수 추가/퇴직) Dropbox 파일을 고치고 저장일을 갱신한다. 이 SKILL.md는 고치지 않는다.

## 2. 이력
- 2026-11-24: 사용자가 붙여넣은 29명 목록으로 처음 만듦 (본인 포함, 이름 없는 주소 1개 있음 — 파일 메모 참고).
