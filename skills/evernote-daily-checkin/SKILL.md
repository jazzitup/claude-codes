# Evernote 데일리 체크인 (공복 유지 / 아침 공부 시간 / 밤 조깅)

## 0. 배경

2026-08-24에 사용자가 기존 3-표 템플렛(Morning Routine 빈 표 + Week/Morning
Study/Jogging/Night writing 빈 표 + Motto/Urgent items 표)이 너무 복잡하다며
간소화했다. 이제 weekly-todo 노트는 **표 2개**로 구성된다 — 자세한 표 구조는
[[evernote-weekly-todo]] 스킬의 4절을 따른다(이 스킬을 만들면서 그쪽도 함께
갱신했다). 이 스킬은 그 첫 번째 표(Morning Routine, 이제는 매일 채워 넣는
표)의 **오늘 칸**을 확인하고, 비어 있으면 사용자에게 물어서 채우는 역할만
한다.

## 1. 언제 실행하나

- **자동**: `~/.claude/settings.json`의 `SessionStart` 훅
  (`~/claude-codes/scripts/evernote-daily-checkin-hook.sh`)이 모든 새 Claude
  Code 세션 시작 시 이 스킬을 참고하라는 `additionalContext`를 주입한다. 이
  훅 스크립트 자체는 고정 문구만 출력하고, 실제 로직은 이 SKILL.md에 있다.
- **수동**: 사용자가 "오늘 체크인 해줘"처럼 직접 요청할 때도 아래 절차를
  그대로 따른다.
- 세션당 한 번만 확인한다 — 같은 세션 안에서 이미 확인했다면(이미 채워져
  있었거나, 인터뷰해서 채웠거나) 다시 묻지 않는다.

## 2. Evernote MCP 연결 확인

`mcp__evernote__*` 도구가 이 세션에 없으면([[evernote-weekly-todo]] 10절 참고
— 로컬 세션은 `claude mcp login evernote` 후 재시작해야 도구가 보인다) 이
체크인을 조용히 건너뛴다. 사용자에게 언급하지 않는다(매 세션마다 "Evernote
연결 안 됨"이라고 알리는 건 소음이다) — 단, 사용자가 직접 "체크인 해줘"라고
요청했을 때는 연결이 안 되어 있다고 알려준다.

## 3. 오늘에 해당하는 주간 노트 찾기

1. `date` (Bash)로 오늘 날짜와 요일을 구한다.
2. [[evernote-weekly-todo]] 2절의 규칙(그 주 일요일이 속한 달 + 그 달의 몇
   번째 일요일인지)으로 오늘이 속한 주의 노트 제목을 계산한다.
3. `mcp__evernote__search_notes({query: "intitle:\"<제목>\""})`로 찾는다.
   없으면(아직 그 주 노트가 안 만들어졌으면) 체크인을 건너뛰고 조용히
   넘어간다 — 이 스킬은 노트를 새로 만들지 않는다(그건
   [[evernote-weekly-todo]]의 역할).
4. `get_note`로 본문을 가져온다.

## 4. 오늘 칸이 채워져 있는지 확인

노트 본문의 **첫 번째 표**(Morning Routine)는 다음 구조다 — 8칸짜리 헤더 행
(첫 칸은 빈 라벨 칸, 이어서 Sun~Sat) 다음에 요일별 값이 아니라 **항목별로
한 행씩** 온다:

- `전날 밤 공복 유지` 행 — 7개 요일 칸, 각각 `O`(했음) 또는 `X`(안 했음)
- `아침 공부 시간` 행 — 7개 요일 칸, 각각 `시:분` 형식(예: `1:30`)
- `밤 조깅` 행 — 7개 요일 칸, 각각 `O`/`X`

오늘 요일이 이 표의 몇 번째 데이터 칸(Sun=1번째, Mon=2번째, ... Sat=7번째)에
해당하는지 계산한다. 각 행에서 그 칸의 내용을 본다:
- 비어 있음(`<div style="text-align:center;"><br/></div>` 형태) → 아직 안
  채워짐
- 그 외 텍스트가 있음(`O`, `X`, `1:30` 등) → 이미 채워짐

세 항목 다 채워져 있으면 아무것도 하지 않고 조용히 넘어간다(사용자에게
언급조차 하지 않는다 — 이미 다 했다는 걸 매번 알리는 것도 소음).

## 5. 인터뷰

비어 있는 항목이 하나라도 있으면, **비어 있는 항목만** 대화체로 하나씩
물어본다(이미 채워진 항목은 다시 묻지 않는다). 예시 톤:

- "어젯밤 공복 유지했어? (O/X)"
- "오늘 아침 공부 몇 시간 몇 분 했어? (예: 1:30)"
- "오늘 밤 조깅했어? (O/X)" — 세션이 아침/낮에 열려서 아직 밤이 안
  지났으면 사용자가 "아직 몰라"/"나중에"라고 답할 수 있다. 그러면 그 항목은
  비워둔 채로 넘어가고, 다음에 채워지지 않은 채로 세션이 열리면 다시 물어보게
  된다(하루 안에 여러 번 물어봐도 괜찮다 — 4절에서 이미 채워진 항목은 걸러
  지므로 중복 질문은 안 생긴다).

O/X 항목에 사용자가 다른 표현으로 답하면(예: "했어", "못했어", "응", "아니")
자연스럽게 O/X로 변환해서 채운다.

## 6. 노트에 반영

`get_note`로 받은 본문에서 해당 행 전체(`<tr>...</tr>`, 라벨 칸부터 7개
요일 칸까지)를 `find`로 삼아 `mcp__evernote__edit_note`
(`mode:"replace"`)로 그 행 전체를 다시 쓴다 — 오늘 칸만 값이 들어가고
나머지 칸은 원래 내용을 그대로 유지한다. 행 전체를 앵커로 쓰는 이유: 7개
요일 칸이 서로 구조적으로 동일해서 칸 하나만 `find`로 집으면 노트 전체에서
여러 번 매치되어 `edit_note`가 모호하다고 거부하기 때문이다. 라벨 텍스트
(`전날 밤 공복 유지`, `아침 공부 시간`, `밤 조깅`)는 각 행에 하나뿐이라
행 전체를 앵커로 쓰면 항상 유일하게 매치된다.

여러 항목을 한 세션에서 채우면 `edit_note`를 항목 수만큼 순서대로 호출한다
(한 번에 하나씩 — 각 호출 후 다음 행의 `find`가 여전히 유효하다).

## 7. 검증 및 보고

채운 뒤 `get_note`로 다시 읽어 오늘 칸에 의도한 값이 정확히 들어갔는지
확인한다. 사용자에게는 "오늘 [항목들] 기록했어" 정도로 짧게 확인해주고
끝낸다 — 장황한 요약 불필요.

## 8. 여러 컴퓨터·세션 동기화

이 SKILL.md는 `~/claude-codes`(git repo, `~/.claude/skills`에 심볼릭 링크)
안에 있어서 기존 auto-pull/push 훅으로 모든 컴퓨터에 자동 동기화된다. 다만
**SessionStart 훅 등록 자체(`~/.claude/settings.json`)는 컴퓨터마다 별도
파일이라 git으로 동기화되지 않는다** — 새 컴퓨터에서 이 체크인이 자동으로
뜨게 하려면 그 컴퓨터의 `~/.claude/settings.json`에도 아래 훅 항목을 한 번
추가해야 한다(직접 `update-config` 스킬을 쓰거나 이 파일 내용을 참고):

```json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "~/claude-codes/scripts/evernote-daily-checkin-hook.sh",
            "timeout": 10,
            "statusMessage": "Checking today's Evernote check-in..."
          }
        ]
      }
    ]
  }
}
```

(기존에 다른 `SessionStart` 훅이 이미 있다면 배열에 새 원소로 추가한다 —
통째로 덮어쓰지 않는다.) 훅 스크립트 자체(`evernote-daily-checkin-hook.sh`)
는 저장소 안에 있으므로 git pull만 되면 자동으로 따라온다.
