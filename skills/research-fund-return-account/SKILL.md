# 연구비 반납 계좌

## 0. 규칙
- 이 SKILL.md는 공개 GitHub repo에 있다. **계좌번호를 이 파일이나 repo 어디에도 적지 않는다.**
- 계좌 정보는 Dropbox 파일에만 있다 (Dropbox 동기화로 다른 컴퓨터에서도 보임):
  `~/Library/CloudStorage/Dropbox/01. 개인서류/contacts/연구비_반납계좌.md`
- 송금·이체는 절대 대신 하지 않는다. 계좌를 알려 주는 것까지만.

## 1. 사용법
1. 위 Dropbox 파일을 읽는다. 없으면 Dropbox 동기화를 확인하라고 알린다(번호를 지어내지 않는다).
2. 질문에는 **은행명과 계좌번호 한 줄로 바로** 답한다 (예: "국민은행 <번호>"). 설명은 사용자가 물을 때만.
3. 필요하면 파일의 메모(반납 후 이체증 제출, 출금계좌로 잘못 보내지 말 것)를 한 줄 덧붙인다.
4. 계좌가 바뀌었다고 하면 Dropbox 파일만 고친다.

## 2. 이력
- 2026-11-24: 사용자가 계좌를 확인하고 저장 요청 (출처: 2023-01 산학지원과 안내 메일).
